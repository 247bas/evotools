About evotools

A set of open-source tools that make building on the Dash Evolution chain easier to start. Testnet to learn on, mainnet when you mean it, built in the open.

Why this exists

The hardest part of Dash Platform is the beginning. You can't just sign up — an identity has to be funded before it exists, which stops a lot of people before they write a line of code.

evotools smooths out those first steps: get a funded testnet identity in a few clicks, then learn the v4 SDK from examples that are tested and ready to run.

What's here

  • Map — where DASH, credits and identities sit, what each move costs, and where any identity's money came from.
  • Onboard — from nothing to a funded identity with a .dash name, and a ready .env.
  • Keygen — one phrase to a funding address and the five identity keys, fully offline, with a copy you can download and run disconnected.
  • Credits — an identity's balance and every way to move it, including a withdrawal back to layer 1.
  • Playground — run the cookbook recipes live in the browser, no install.
  • Explorer — identities, names, contracts, tokens, documents and the shielded pool, with proofs.
  • dash-name — check and claim a .dash username for your identity.
  • Contests — every .dash name masternodes are voting on, and every one they decided.
  • Cookbook — verified, runnable @dashevo/evo-sdk v4 recipes.
  • create-evo-app — scaffold a Platform app with npm create evo-app.

All of it runs in your browser on testnet and mainnet. No server holds your keys, because there is no server.

What this runs on

evotools is a thin layer over other people's work: @dashevo/evo-sdk and dashcore-lib by Dash Core Group; the masternodes serving DAPI, which answer every lookup and broadcast here; the Dash Bridge by PastaPastaPasta, where testnet DASH comes from; pshenmic's Platform Explorer, whose index makes the contests list and the funding trace possible at all, because Platform can prove a thing you name but cannot list things; and the Insight API behind every layer-1 read. All of it is public infrastructure this project uses as a guest.
