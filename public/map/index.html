Where your Dash actually lives

Two chains carry the same money under different rules. You cannot send DASH to a dash1… address, an identity holds no coins, and credits only leave through a withdrawal. Paste an address, an identity or a name and see how it stands.

This page never asks for a recovery phrase or a private key. It does not need one: an address already carries the key hash that finds the identity it opens, and an identity names the address that funded it. Public in, everything out.
